

\# Lab Architecture



\## Purpose



This lab explores how AWS activity logging and threat detection

support a cloud security investigation.



\## Components



\### AWS CloudTrail

Records supported AWS API activity for investigation.



\### Amazon GuardDuty

Analyzes supported data sources and produces security findings.



\### AWS IAM

Controls access to AWS resources and supports least-privilege

security practices.



\### Terraform

Defines and manages the lab's infrastructure as code.



\## Investigation Workflow



1\. Generate authorized test activity.

2\. Review relevant CloudTrail events.

3\. Inspect GuardDuty findings where available.

4\. Assess the affected identity or resource.

5\. Contain the simulated threat in the test environment.

6\. Verify recovery and document lessons learned.



\## Deployment Status



Architecture and services will be updated to reflect the resources

actually deployed and tested.
