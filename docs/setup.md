

\# Setup Guide



\## Prerequisites



\- An AWS account with appropriate permissions

\- Multi-factor authentication enabled for the root user

\- Terraform installed

\- AWS CLI v2 installed

\- Git installed

\- A Windows PowerShell terminal



\## Local Project Setup



1\. Clone this repository or download the project.

2\. Open PowerShell in the project directory.

3\. Verify Terraform with `terraform -version`.

4\. Verify the AWS CLI with `aws --version`.

5\. Configure a named AWS CLI profile.

6\. Verify the AWS identity before deploying resources.



\## Deployment



Terraform commands and resource deployment instructions will

be added after the infrastructure configuration is reviewed.



Do not run `terraform apply` until the AWS identity, region,

permissions, and expected costs have been checked.



\## Cleanup



Resource-specific cleanup instructions will be documented

after deployment has been tested.
